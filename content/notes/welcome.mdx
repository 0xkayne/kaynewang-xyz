这里是学习笔记，不是课程总结。

我会把最近在看的技术、踩过的坑、还没想明白的概念写下来。笔记可以短，也可以之后再补。

和博客的区别很具体：

- 笔记偏过程，记的是「我正在学什么」
- 博客偏成文，把一件事说完
- 还没展开的想法仍放在博客里，标成「想法」

<Callout>
第一篇先占个位置。后面的笔记会从具体问题写起，而不是先列一个空目录。
</Callout>

本地看这个站，用的就是常见的 Next.js 命令：

```bash
npm run dev
```

如果你是从 GitHub 或 X 点进来的，从这篇往下看就好。
